# 공휴일 외부 데이터 출처와 사용 시점

조회일: **2026-11-11 (Asia/Seoul)**. 사용한 달력 사실·공식 발표는 모두 **2026-06-30 이전 공개**된 자료다. 조회일과 정보 공개일을 구별한다. 실현된 교통량·날씨·행사 결과·투표 결과는 수집하거나 사용하지 않았다.

대회에서 허용한 2025-01-01~2026-10-31 공휴일 특징을 `src/holiday_calendar.py`에 정적으로 인코딩했다. 모듈은 같은 공개 달력에 있는 2026-12-25까지 지원하지만 모델의 실제 예측 범위는 10월 31일까지다. 외부 API·인터넷 없이 재현된다.

## 라이선스·재사용 기록

- 우주항공청 **2026년 월력요항 발표** 페이지는 **공공누리 제1유형(출처표시)**를 표시한다.
- 우주항공청 **2025년 월력요항**의 [원 게시물](https://www.kasa.go.kr/prog/bbsArticle/BBSMSTR_000000000010/view.do?bbsId=BBSMSTR_000000000010&nttId=B000000000633Wg5pO7)은 **공공누리 제2유형(출처표시·상업적 이용금지)**를 표시한다. 대회가 요구하는 비상업적 이용 범위로 출처를 남긴다.
- 정책브리핑의 인사혁신처·고용노동부 보도자료 전재 페이지는 **텍스트에 한해 공공누리 제1유형**을 표시한다. 본 프로젝트는 날짜·명칭·공개일을 정리하며 사진·그림·서식 파일을 재배포하지 않는다.
- 행정안전부 보도자료는 **공공누리 제1유형**을 표시한다.
- 서울선관위 일정 안내는 **공공누리 제4유형(출처표시·상업적 이용금지·변경금지)**를 표시한다. 원 이미지·홍보물은 복제하거나 수정하지 않았으며 공개 선거일의 교차 확인에만 사용했다. 모델에 쓰는 날짜는 이전에 공개된 KASI 달력에도 있다.
- KASI의 [공공데이터포털 특일 정보](https://www.data.go.kr/data/15012690/openapi.do)는 **이용허락범위 제한 없음**, 무료, 등록 2015-12-21·수정 2023-03-29로 표시한다. [천문우주지식정보 카탈로그](https://www.data.go.kr/catalog/2810264/fileData.json) 역시 월력요항 등을 포함하며 **이용허락범위 제한 없음**, 수정 2023-11-15를 명시한다. 이는 달력 데이터 이용 조건의 참고 기록이며 이번 작업에서 인증 API를 호출했다고 주장하지 않는다.
- 코드는 위 달력의 사실을 직접 작성한 정적 날짜 목록으로 보관한다. 보도자료 본문이나 디자인을 통째로 복제하지 않는다. 출처 URL·기관·공개일·조회일은 이 문서에 남긴다.

## 예측 시점과 Local CV

기본 호출 `calendar_features(dates, as_of="2026-06-30")`은 최종 예측 시점에 공개된 달력을 적용한다. 검증 또는 과거 학습 origin을 만들 때에는 **그 origin을 as_of로 전달**한다. 임시공휴일·신규 공휴일은 다음 조건으로 활성화된다.

| 대상 날짜 | 내용 | 최초 사용 가능한 공개일 |
| --- | --- | --- |
| 2025-01-27 | 임시공휴일 | 2025-01-14 |
| 2025-06-03 | 대통령선거 임시공휴일 | 2025-04-08 |
| 2026-05-01 | 노동절의 관공서 공휴일 적용 | 2026-04-06 |
| 2026-07-17 | 제헌절 공휴일 재지정 | 2026-02-03 |

공개일 전이면 해당 날짜의 `is_holiday=0`, `holiday_type=0`으로 처리한다. ‘나중에 지정될 휴일’이라는 별도 마스크를 모델에 주지 않는다. `is_labor_day`는 두 해 모두 5/1이라는 기존 달력·노동 기념일 표시다. **2025-05-01은 관공서 공휴일로 처리하지 않는다.**

주말은 named holiday와 구별한다. `is_holiday`에는 정기 일요일을 넣지 않고 `calendar_is_weekend`, `is_rest_day`에서 토·일을 표현한다. `is_holiday_eve`, `is_after_holiday`, `is_bridge_day`도 같은 as_of의 달력만 이용한다. 승차량을 휴일이라는 이유로 0으로 강제하지 않는다.

## 경계 조건 확인

- 2025-05-05는 어린이날과 부처님오신날이 겹치지만 한 날짜 한 행으로 인코딩한다. 5/6은 대체공휴일이다.
- 2025-10-08은 추석 대체공휴일이다.
- 2026-05-25, 8/17, 10/5는 대체공휴일이다.
- **2026-09-28은 공휴일이 아니다.** 공식 연휴는 추석 9/24~26과 일요일 9/27까지다.
- 2026-06-06 토요일 현충일은 공휴일이지만 **6/8을 대체공휴일로 추가하지 않는다.**
- 최종 달력의 날짜 수는 2025년 19일, 2026년 22일이다(정기 일요일 제외, 중복 공휴일은 한 날짜). 테스트 2026년 7~10월에는 9개 날짜가 포함된다.

상세 날짜 목록은 `reports/holiday_calendar.csv`에 있다. 이 목록은 감사·재현용이며 `known_since`, `source_id`를 모델 입력으로 넣지 않는다.
