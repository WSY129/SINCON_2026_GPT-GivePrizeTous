# 모델 선정과 요청 목록의 적용 범위

## 실제 과제와 선택 기준

71개 역 × 하루 18구간의 **123일 승차량 예측**이다. 역·노선·과거 하차·달력·사전 공표된 공휴일을 활용한다. 좌표·거리·인접 그래프는 없다. 고정 시간 CV의 RMSLE와 재현 비용으로 선택한다. [공식 출처](official_sources.md)와 [달력 출처](holiday_sources.md)를 따른다.

## 요청 모델군별 결정

| 요청 모델군 | 요청한 후보 | 이번 결정 |
|---|---|---|
| 규칙 시계열 | TimeH2O-v1, Timestral-209M, Chronos-2 | 향후 후보. 체크포인트·공개 시점·라이선스·입출력 지원 미검증으로 기본 실행 제외 |
| 공변량 예측 | GBDT 3종, TabM, TabPFN-TS, TimeXer, TimeMixer++ | LightGBM·CatBoost·XGBoost 구현. 나머지는 별도 후보이며 구현·파인튜닝 완료로 보고하지 않음 |
| 패치 기반 대안 | PatchTST | 직접 다중 horizon 후보로 보류; 현재 MLP와 동일 모델이 아님 |
| 파형 분류 | RocketPFN, HIVE-COTE 2, MultiRocket, Hydra, MantisV2 | 분류 라벨 없는 승차량 회귀이므로 제외 |
| 이상 탐지 | HieraNTP, HYDRA, TimesNet | 이상 점수 제출 과제가 아니므로 제외. 급등은 회귀 진단으로 분석 |
| 불규칙 이벤트 | ReIMTS, iTimER, GRUwE | 관측 기간 안의 역·시간 격자가 규칙적이므로 우선순위 낮음 |
| 물리적 시공간 | STBP, STID, STAEformer, PDFormer, STPFormer, NeST | 거리·연결·전파 근거 없이 역 ID로 물리 그래프를 만들지 않음 |
| 좌표 없는 다개체 | iTransformer, Crossformer | 동조성을 활용할 향후 후보. 현재는 origin 이전 노선·전체 집계 사용 |
| 생성형 학습 | LoRA/SFT, 강화학습 후처리 | 숫자 회귀 과제에 필요한 단계가 아니므로 미적용 |

후보의 실재·SOTA 지위·메모리를 모두 검증한 목록은 아니다. 사전학습 모델은 기준일 이전 공개와 이용 조건을 확인해야 추가할 수 있다.

## 현재 구현한 7개 설정

1. `seasonal7`: 기준일 이전 마지막 같은 요일 값을 반복하는 계절 기준선.
2. `weekday_mean`: 최근 같은 역·시간·요일의 평균 기준선.
3. `lightgbm_small`: 작은 leaf 수의 전역 회귀.
4. `lightgbm_large`: leaf 수·반복 수를 늘린 비교 설정.
5. `catboost`: 역·노선·요일·시간 범주형을 사용하는 회귀.
6. `xgboost`: histogram 트리와 깊이·정규화 제한을 사용하는 회귀.
7. `mlp`: 학습 구간에서만 맞춘 정규화·결측 마스크를 가진 작은 신경망.

외부 가중치는 사용하지 않는다. MLP는 TabM·RevIN이 아니다. 실제 점수·시간·성공 여부는 `outputs/baseline/cv_scores.csv`와 실행 요약에 기록한다.

## 손실·검증·앙상블

공식 RMSLE는 `sqrt(mean((log1p(pred)-log1p(y))**2))`이다. 따라서 `z=log1p(y)`에 L2를 학습하고 `expm1`으로 한 번만 복원한다. RMSLE에서 로그 공간 평균을 원단위 평균으로 바꾸기 위한 분산 보정은 자동 적용하지 않는다.

개발 fold 1·2의 OOF로 모델 중복·가중치·보정을 정하고 fold 3은 고정 결과 감사에만 사용한다. 로그 잔차 상관이 0.95를 넘는 중복 후보를 제거하고 비음수·합 1 가중치로 로그 공간에서 결합한다. 6~7개 모델이나 상관 0.70~0.88을 강제하지 않는다. 실험 7개와 최종 채택 개수는 다를 수 있다.

원단위 MBE는 진단이다. 원단위 평균 편향·MAE용 중앙값 보정을 자동 적용하지 않는다. 로그 편향도 개발 OOF 개선이 있을 때만 적용하며 audit에서 재추정하지 않는다.

## 전처리와 자원

트리는 원본 규모의 피처를 사용한다. 과거 집계는 origin에서 고정하며 미래 실측 하차와 신규 역 관측 전 0 채우기를 배제한다. 신경망 정규화는 학습 자료에만 맞춘다.

`linear_tree=True`는 메모리·스케일링 요구가 있는 별도 후보이며 L1과 호환되지 않는다. T4·FP16·DDP·checkpointing은 선택 사항이다. 대회는 별도 시간 제한 없이 Kaggle/Colab 재현 가능 규모를 요구한다. DDP는 VRAM을 합치지 않는다. 로컬 실행을 T4 검증으로 보고하지 않는다.
