## 이전 0.291005와의 구분

이전 `0.291005`는 Codex가 별도로 만든 `seasonal7`의 로컬 검증 점수다. 2026-02-27까지의 마지막 같은 요일 승차량을 복사해 02-28~06-30의 123일을 평가했다. 공식 베이스라인 다운로드로 얻은 점수도, Kaggle 점수도 아니다.

운영진과 **동일한 cutoff 02-28·검증 기간 03-01~06-30**으로 단순 계절 복사를 다시 계산하면 **0.2897381687956004**다. 이는 단순 비교모델의 로컬 성적이며 공식 베이스라인의 정의를 바꾸지 않는다. 기간이 다른 0.291005와 공식 0.30770을 그대로 동일 조건 비교로 제시하지 않는다.
