## 0. v21 (2026-11-13 오후)

**바뀐 것**
1. **주말 명절 라벨 수정** (`src/v21/kinds.py`)
   - `src.v8.core.day_kinds`는 추석·설에 붙은 토·일도 `lunar_adj`(평일에서 배운 명절 감소)로 분류해, 주말 수준에서 감소를 한 번 더 뺐다. 2025-10-05(일)에 트리가 −0.57 로그 과소였다.
   - 이런 날을 `long_sat`/`long_sun`으로 바꿔 패널을 다시 만들고 트리를 재학습했다(평가셋 해당일 2026-09-26).
2. **기각한 것**
   - 직전 28일 잔차 드리프트 특징: 기준일이 연말인 Fold 3에서 해로워 제외했다(제거 실험으로 확인, 최종 멤버는 `--drop-last 2`로 학습).
   - 날 전체 수준 버스 항: 일 단위 상관이 추석 0.008, 설 0.41로 명절마다 달랐다.
   - 3-방향 결합, CatBoost GPU(스택 가중 0).
3. **스택**(`src/v21/chain.py`): v15 스택 코드에 멤버만 교체했다.
   - 보정 단계는 v20e(v15)와 같은 **행사·방학·저수요·휴일**이다. 허용치 `V21_STEP_TOL=1.5e-4`는 이 구성을 재현하도록 정한 값이고, 점수로 고른 값이 아니다. 휴일 단계는 Fold 3에서 +0.00013으로 경계선이었다.
   - 평가셋 1단계 가중: **v10 0.399 / LightGBM lgb_hk 0.429 / GPU XGBoost xgb_g11k 0.171** (xgb_ik는 0).
4. **2단 결합**(`src/v21/blend2.py`, `final.py`): v21 체인 × w + v19(v20e의 기반) × (1−w).
   - w는 폴드마다 나머지 폴드에서 고르되, 그 폴드와 날짜가 겹치는 날은 뺐다(날짜 차단).
   - 결과는 1.0 / 0.9 / 0.9 / 0.9, 평가셋은 0.9.
5. **명절 버스 단계**(`src/v21/busholiday.py`, 검증 통과)
   - 대표 정류장의 명절 버스 이상치(같은 창의 평소 요일 대비)를 역 간 편차로 바꿔 지하철 예측을 이동한다.
   - 추석에서 맞춘 계수 0.200을 설에, 설에서 맞춘 계수 0.135를 추석에 적용해 검증했다(역 간 상관 0.52 / 0.38). 평가셋 계수는 0.169다.
   - 평가셋 이동: 추석 88개 역-일(26개 역)과 10월 연휴 136개 역-일(28개 역), 평균 절대 이동 0.074 / 0.073 로그, 부호 평균 −0.026 / −0.029.
   - 한계: 10월 단독 연휴 유형은 학습 기간에 검증하지 않았다. 30개 역은 검증 예측의 특수일 오차 순으로 골랐으므로 개선폭이 다소 낙관적일 수 있다.
6. **v21e**(`src/v21/extras.py`, 검증 불가): v20e 항목(여름 집단휴가, 14건 = 시나리오 13 + 마라톤 배율 1)을 v21 위에 다시 적용했다.
   - 송도 맥주축제 18~23시는 낮추기만 한다(50칸): 2026 버스 증가분이 2025의 0.05~0.46이고, 2026부터 유료 입장.
   - 부평삼거리 추석 당일(9/25) 08~16시를 2026 설 당일 실측(10,124명) 쪽으로 확률 0.5 가중: 8,850 → 9,466명.

**단일 모델**(가중 4-Fold, 시드 평균, 로컬 검증(OOF)): lgb_hk 0.16943 (v20e의 lgb_h 0.17350), xgb_ik 0.17126 (xgb_i 0.17490), xgb_g11k 0.17127 (드리프트 특징을 넣은 xgb_g11 0.17177). 전체 표: `outputs/ensemble_v21/SINGLE_MODELS_V21.csv`.

## 3. 검증 체계 (모든 버전 공통)

- **시간순 4-fold**: 원점 2025-08-30, 2025-10-30, 2025-12-30, 2026-02-27. 각 폴드는 원점 다음 123일을 예측한다(평가 기간과 같은 길이).
- **네 가지 지표**: 전체 OOF, 가중 4-Fold(0.15 / 0.15 / 0.35 / 0.35), Fold 3+4, Fold 4.
- **중첩·날짜 차단 적합**: 보정 계수나 앙상블 가중을 fold k에 적용할 때는 다른 폴드에서만 맞춘다. 이때 fold k의 날짜와 겹치는 학습 행도 뺀다(폴드끼리 두 달이 겹치기 때문).
- **채택 규칙**: 전체 OOF가 좋아지고 어느 폴드도 나빠지지 않을 때만 채택한다(허용 오차 1e-5). 기각한 실험은 각 버전 `RESULTS*.md`에 남겼다.
- **한계**:
  - 7~8월을 덮는 폴드가 없어 여름 효과는 로컬에서 검증할 수 없다.
  - Fold 1·2에는 전년 같은 시기 자료가 없다.
  - 평가 기간 행사 항목("e" 파일)도 로컬에서 측정할 수 없다.

## 4. 전처리와 특징

- **기준선(anchor)**: 원점 직전 수준 + 여러 해 일별 계절 곡선 + 휴일 효과 + 신규 역 성장. 트리 모델은 기준선에 대한 로그 잔차를 학습한다.
  - v2는 56일·28일 정제 평균을 썼다. v9 이후는 이 구조적 기준선으로 바뀌었다.
- **신규 역(검단호수공원 3107, 신검단중앙 3108, 아라 3109, 2025-06-28 개통)**: 개통일 행을 빼고, 감쇠 추세(Theil-Sen, v4/v5)와 성장 보정(v7, v19)을 따로 둔다.
- **집계 단절 보정**: 2025년 이력을 2026년 기준으로 환산한다(v9 이후).
- **학습 행 정리**: 운휴·이상치 9건, 신규 역 개통 162행, 잘못된 행사 라벨이 붙은 날(v15에서 3건)을 학습 대상에서 뺐다.
- **주요 입력**(v11 50개 → v14·v15 74개):
  - 달력: 요일, 휴일 종류, 명절 앞뒤 거리, 방학 비율, 집단휴가 주.
  - 기상: 시간대별 강수·기온·일사·풍속·운량, 기상특보.
  - 경기·행사: 관중, 종료 시각, 점수차, 행사 종류, 행사 시작 후 경과 시간.
  - 역 특성, 전년 동기 이력, 서울·인천교통공사 이력에서 만든 계절 지수.

## 8. 미해결 문제

1. **평가 기간 항목은 로컬 검증이 불가능하다.**
   - 행사 시나리오 확률과 크기, 여름 집단휴가 폭이 여기에 해당한다.
   - 일부 종료 시각은 출처가 약하다(PLAVE·최강야구는 나무위키 위주, 이슬라이브는 21:30과 22:20이 엇갈림).
2. **여름 폴드가 없다.** 7~8월 동작(폭염·휴가·축제)은 2025년 학습 자료와의 비교로만 점검했다.
3. **Fold 1이 약하다.** 로컬 검증(OOF) 0.1803으로 다른 폴드 0.159~0.161보다 높다. 전년 자료가 없는 구간이기 때문이다.
4. **모델 간 불일치가 행사 역에 몰려 있다.**
   - 평가셋에서 v10과 새 트리(LightGBM·XGBoost)의 로그 차이 상위 500칸 중 166칸이 문학경기장, 46칸이 송도달빛축제공원이다.
   - 예: 맥주축제 8/22 22시에 v10은 3,495명, 트리는 약 400명이다. 현재는 행사일 규칙에 따라 v10 값을 쓴다.
5. **신규 역 성장의 방향이 확정되지 않았다.**
   - 3108·3109는 감쇠를 적용했고, 3107은 반대로 과소 예측 경향이 있다.
   - 버스 정류장 추이는 9/19 노선 신설로 섞여 있다.
6. **재현성.**
   - GPU 단계(v2·v4·v5·v9·v11)는 다시 학습해 보지 않았다.
   - x86·코랩 등 다른 장비에서 확인하지 않았다.
   - 외부 자료 라이선스 칸은 초안이다.
   - 버스 표는 사이트 화면 조회값이며 자동 수집 코드가 없다.
7. **구조적 하한.**
   - 오차 제곱합의 약 35%는 칸 단위 계수 잡음(Poisson)이라 줄일 수 없다(추정).
   - 역-일 합계를 완벽히 알아도 로컬 약 0.15가 한계다(추정).

## 9. 남은 개선 포인트

1. **버스 기반 행사 규모 추정을 검증 가능한 형태로 만들기**(`src/v21/run.py`, 작성만 하고 실행하지 않음).

   - 낮 경기(14시 시작) 배율이 저녁 경기와 다른지 반영해야 한다(조사 중).
2. **송도달빛축제공원 맥주축제·펜타포트**
   - 2026-11-13에 2025년(학습 기간)과 2026년 역 출구 정류장 버스를 같이 조회했다.

   - 원본은 `data/external_bus/stcis_20261113/`, 대조표는 `analysis/handoff_20261113/02_bus_raw/tables/`.
3. **추석 성묘(부평삼거리·인천가족공원 정류장)**
