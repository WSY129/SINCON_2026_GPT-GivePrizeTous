## 1. 규칙과 두 파일의 차이

사용자가 운영진에 직접 확인한 내용: 평가 기간(2026-07~10)의 **지하철 승하차 수치는 출처를 불문하고 금지**, 실제 경기 결과·관중·종료 시각·취소, 실측 날씨, 실제 개최 행사는 평가 기간 기록도 사용 가능.

|  | 보험용 (precutoff) | 주력 (v8) |
|---|---|---|
| 쓰는 정보 | 2026-06-30까지 관측·공개된 것만 | 왼쪽 + 평가 기간의 실제 경기(관중·종료 시각·취소), 실측 강수, 실제 개최 행사 |
| 모듈 | v7 → 다년 계절 지수 → 역별 공휴일 효과 | 왼쪽 → 실측 강수 → 부천 실제 경기 → 문학 실제 경기 → 이슬라이브 |
| 평가 기간 승하차 | 사용 안 함 | 사용 안 함 |
| 코드 보장 | 실측 자료 로더를 막아도 같은 파일이 나오는 테스트 | — |

## 2. 모듈 설명

### P1 다년 계절 지수 (보험용·주력 공통)
- 자료: 인천교통공사 월별 역×시간대 승하차 2015-10~2024-12(팀 공유 자료, train 기준으로 보정된 값). 파손 표시 월(2015-11 일부)과 2020~2022년은 제외.
- 계산: 월 합계를 그 달의 평일·토·일공휴일·명절 일수로 나눠 "평일 하루 수준"으로 환산한다(요일 비율은 기준일 이전 train에서 역×시간별로 계산). 각 정상 연도(2016~2019, 2023, 2024)에 대해 [대상 월 수준 − 기준일 직전 두 달 수준]의 로그 변화를 구하고 가중 중앙값을 낸다. 가중치는 최근 연도일수록 크고(1, 1, 1, 1.5, 2.5, 3), 9·10월은 추석이 올해와 같은 달에 있던 연도에 2배를 준다(2026년 추석은 9월).
- 구조 변화: 역×월 단위로 최근 2년과 그 이전의 변화가 로그 0.12 넘게 다르면 최근 2년만 쓴다(국제업무지구 8월, 인천대입구 방학, 부평구청 등이 여기에 걸린다). 시간대별 값은 역 평균 쪽으로 절반 수축, 보정폭은 ±0.20으로 제한.
- 적용: 예측이 내포한 변화(대상 월 평일 예측 평균 − 직전 두 달 실제 평균)와 지수의 차이에 계수를 곱해 더한다. 신규 3개 역과 문학경기장은 대상이 아니다.
- 로컬: 0.20214 → 0.19243. 단순 중앙값만 쓴 경우 0.19314.

### P2 역별 공휴일 효과 (공통)
- 기준일 이전의 공휴일마다 [그날 − 같은 요일 평소 중앙값]을 역×시간별로 구해 범주별 평균을 낸다. 범주: 평일 공휴일, 토요일 공휴일, 근로자의 날, 명절 당일, 명절 전후, 신정, 징검다리, 연휴에 낀 토·일.
- 예측에서는 주변 같은 요일 평소 예측의 중앙값에 그 효과를 더한 값을 만들고, 기존 예측과 섞는 비율을 범주군×(보통역/특이역)별로 적합한다. 특이역 = 자기 효과가 전체 역 중앙값과 로그 0.4 이상 다른 역(부평삼거리 성묘, 산업단지 역 등).
- 로컬: 0.19243 → 0.18989. 공휴일 발표일을 지킨다(2026-07-17 제헌절은 2026-02-03 지정).
- 지시서의 "연휴 마지막 날"은 연휴에 낀 주말 범주로 넣었고 계수가 0.22(보통역)로 작다. 테스트 구간에 징검다리 평일은 없다.

### 실측 모듈 (주력만)
- **A4 실측 강수**: 기준일 이전 자료에서 역×(평일/휴일)×시간별 비 효과를 구하고(운행시간 강수 1~10mm, 10mm 이상 두 단계), 대상일의 실제 강수 단계에 해당하는 효과에서 평균 효과를 뺀 만큼 보정한다. 전년 같은 요일(−364일)의 비가 예측에 남긴 흔적도 반대 부호로 넣는다. 로컬: 0.18989 → 0.18850. 2026년 7월은 비 온 날이 22일로 많다.
- **A2 부천**: 실제 홈경기 관중 × 유출 비율(킥오프+115분 기준)로 교체. 로컬: 0.18850 → 0.18822.
- **A1 문학**: 확률 혼합 대신 실제 개최 여부·관중·분 단위 종료 시각을 쓴다. 경기일 = 평소 프로필 + 관중 × 유출 비율(종료 전 120분~종료 후 150분, 16개 구간, 로그 공간 적합). 경기 없는 시즌 날 = 평소 프로필에 남은 급등 확률만 반영. 발표된 콘서트 날은 v7 값을 유지. 로컬: 0.18822 → 0.18550, 문학경기장역 0.553 → 0.483.
- **A3 이슬라이브**: RESULTS_V8 5절. 검증 불가.

## 4. 위험

- 계절 지수 계수는 fold에서 0.80~0.90이고 테스트에는 0.86을 쓴다. 테스트에서는 v4·v5가 이미 작년 7~10월을 알고 있어 fold보다 효과가 작을 수 있다(전년 정보가 있던 Fold 4에서도 0.19008 → 0.18305였다).
- 문학 회귀는 과거 124경기로 적합했다. 연장전·우천 중단 경기는 종료 시각과 실제 퇴장 시점이 어긋난다.
- 주력 파일은 운영진 답변의 해석에 의존한다. 해석이 달라지면 보험용 파일을 쓴다.
