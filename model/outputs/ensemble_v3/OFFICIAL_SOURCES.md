## 제외

- KBO: 사용자가 별도 허가 없음, 사용 가능한 출처만 반영하도록 확정. [KBO 이용약관](https://www.koreabaseball.com/Etc/Policy.aspx)의 가공·재사용 제한에 대한 허가를 확인하지 못했으므로 원편성표를 학습·추론·배포 패키지에서 제외했다. production kbo 목록은 비어 있다.
- 송도맥주축제: 마감 이전 발표일과 재사용 조건을 모두 확인하지 못해 제외했다.
- 실제 대학·고교 학사력: 공식 개별 학교 일정으로 사용하지 않았다. 코드의 방학/개강 범위는 사용자 지정 계절 proxy다.

## 내부 데이터로 계산하는 정보

- 9개 급감 관측 키는 사용자가 제공한 분석 후보를 원자료에서 마스킹한다. 외부 사고 원인은 검증하지 않았으므로 “확인된 침수·설비장애”로 단정하지 않는다.
- 개통 특수는 3역 × 3일 × 18시간 = 162행이다. 9개 키와 합쳐 171행이다. Gemini의 54/63행 설명은 계산 오류다.
- 마스킹은 학습 타겟 후보와 과거 피처 집계에만 적용한다. CV 정답은 폴드당 157,194행 모두 보존한다.
- 관측 승하차가 0이라는 이유만으로 제거하지 않는다. 반복적 경기장·축제 스파이크도 일괄 삭제하지 않는다.
- 출퇴근 비대칭은 origin 이전의 정제된 평일 승하차에서 계산한다. 미래 하차량은 보조 학습 타겟에만 사용한다.

## 신호 한계

보수적으로 적용한 2025 축제 공개일과 14일 간격 origin 때문에 축제 플래그가 학습에서 상수일 수 있다. 신경망은 학습에서 상수였던 연속 입력을 추론에서도 0으로 중립화한다. 따라서 축제 일정 추가만으로 점수 향상을 주장하지 않는다. KBO 일정이 없으므로 문학경기장 경기일 급등을 직접 구분하는 신호는 이번 버전에 없다.
