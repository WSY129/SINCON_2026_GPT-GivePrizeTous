# ensemble_v9 설계 (V9_DESIGN)

작성 2026-11-12. 점수는 모두 로컬 검증(OOF)이다. 리더보드 점수는 쓰지 않는다.

## 1. 왜 다시 학습하는가

- v2·v4·v5(v7·v8의 기반)는 "직전 수준"을 기준선으로 삼고 1.5년치 자료로 계절 변화를 배웠다. 목표 계절을 한 번도 못 본 채 예측하는 fold가 많았고, v7에서 새로 학습한 평형 모델 10개도 같은 이유로 기각됐다.
- v8은 그 위에 다년 계절 지수·공휴일 효과·실측 강수·실제 경기를 **후처리**로 얹어 0.20214 → 0.18550(중첩 LOFO)을 얻었다. 후처리는 계수 하나로 섞는 것이라 상호작용(비 오는 주말의 공원 역, 방학 중 비 오는 날의 대학 역 등)을 담지 못한다.
- v9는 같은 구조 정보를 **기준선과 입력 특징**으로 넣어 모델이 직접 배우게 한다.

## 2. 단일 앵커

`anchor(기준일, 대상일, 역, 시간) = 수준 + 계절 + 공휴일`

| 항 | 정의 | 자료 |
|---|---|---|
| 수준 | 기준일 이전 70일 안의 같은 요일(평소 날) 최근 8일 중앙값 | train (2026년 집계 기준으로 환산) |
| 계절 | 대상 월의 평일 하루 수준 − 기준일 직전 두 달 수준, 정상 연도(2016~2019, 2023, 2024)의 가중 중앙값. 최근 연도 가중, 9·10월은 추석이 같은 달인 연도 2배, 구조 변화 역은 최근 2년만, 시간대 값은 역 평균으로 절반 수축 | 공사 월별 승하차 2015~2024 |
| 공휴일 | 대상일의 범주(평일 공휴일, 토요일 공휴일, 명절 당일, 명절 전후, 신정, 근로자의 날, 징검다리, 연휴 주말)에 대한 역×시간 효과. 기준일 이전 공휴일에서 측정 | train, 공휴일 달력(발표일 준수) |

학습 목표는 `r = log1p(y) − anchor`. 모든 행(학습용 가상 기준일, 검증 fold, 최종 추론)이 같은 함수로 앵커를 만든다.

**집계 단절 보정.** train의 2025년분은 공사 월별 자료의 0.74~1.00배이고 2026년분은 같다. v9는 2025년 이력을 역×시간 배율로 2026년 기준에 맞춘 뒤 수준·추세·전년 특징을 계산한다. 예측은 2026년 기준으로 나오며, 2025년 날짜의 검증 정답과 비교할 때만 다시 환산한다.

앵커만으로 낸 fold별 RMSLE(학습 없음): Fold 1 0.229, Fold 2 0.193, Fold 3 0.202, Fold 4 0.220. v7의 중앙값 기준선은 0.242, 0.200, 0.225, 0.276이었다.

## 3. 입력 특징 (68개 = v7 패널 48개 + 20개)

| 묶음 | 특징 |
|---|---|
| 구조 | prior(계절 항), prior_ok, hol_eff(공휴일 항), cat(날 범주), anchor_gap(앵커 − v7 기준선) |
| 실측 기상(대상일) | wet(운행시간 강수 0 / 1~10mm / 10mm 이상), rain_mm, rain_h(그 시간 강수), rain_prev2(직전 2시간), temp_h, tmean, tmax |
| 기상 이력 | wet_ly(364일 전 강수 단계), wet_share8(수준 계산에 쓰인 8일 중 비 온 날 비율) |
| 역 특성 | r_sat, r_sun(주말/평일 비율), commute(출퇴근 시간 비중), basis(집계 배율) |
| 실제 경기 | game_att(문학·부천의 그날 관중), game_rel(종료 시각 대비 시간) |
| v7 패널 | 수준·추세·최근 편차, 달력, 예측거리, 전년 같은 요일 기반 계절·성장, 문학 일정 상태, 행사 표시 |

절대 계절 특징(월, 연중 일)은 넣지 않는다. 계절은 prior가 맡는다.

변형 `_w0`: 대상일 실측 기상과 실제 경기 특징을 뺀 것. `_w0` 모델만 도는 실행은 평가 기간의 기상·경기 파일을 아예 읽지 않는다(보험용).

## 4. 모델과 수렴 규칙 (v7과 동일)

- 트리: LightGBM(CPU), XGBoost(CUDA), CatBoost(GPU). 학습률 0.025, 최대 4000회, 인내 250.
- 신경망: TabM(K=16, 384), ST-Graph, MDN. 워밍업 3에폭 + 코사인 + 마지막 5에폭 SWA.
- 엄격 예측: 트리는 다른 fold들의 최적 반복 수 평균, 신경망은 고정 일정 SWA.
- 최종: 기준일 2026-06-30, 시드 2026·2027, 트리는 Fold 3·4 최적 반복의 1.1배.
- 학습 표본: 7일 간격 가상 기준일, 약 290만 행. 검증 기준일 6개(Fold 1~4, Fold_Hot26, Fold_Summer25).

## 5. 결합과 판정

- v9 모델은 v8 예측과 볼록 결합한다(가중치는 중첩 LOFO). 문학경기장역과 행사·경기 역-날짜는 v8 값(전용 회귀)을 유지한다.
- 주력: v8 주력 + 실측 특징 모델. 보험용: v8 보험용 + `_w0` 모델.
- 채택 조건: 중첩 전체 점수 개선, 나빠지는 fold 없음.
- 비교 기준: 집계 기준을 fold마다 하나로 맞춘 "정렬" 채점(기준일이 2025년인 fold는 2025년 기준, Fold 4는 2026년 기준). 원래 정답 기준 수치도 함께 적는다.

## 6. 실행

```bash
# 포드
python -m src.v9.train cv --models lgb,xgb,cb,stg,tabm,mdn
python -m src.v9.train cv --models lgb_w0,xgb_w0,cb_w0
python -m src.v9.train finalize
python -m src.v9.train final --models <결합 가중치가 0보다 큰 모델>
# 로컬
python -m src.v9.blend
```
