## 3. 코랩 재현성 점검

- **연산 규모는 코랩에서 가능하다.** 학습 행 약 150만 × 입력 74개. LightGBM 한 번 약 95초, XGBoost 20~30초, CatBoost 40~60초(모두 CPU 12스레드 기준). v15의 재학습 전체(LightGBM 15회 + XGBoost 30회)는 CPU로 약 40분, v12~v19의 스택·보정은 각각 수 초~1분이다.
- **그러나 지금 상태로는 한 번에 재현되지 않는다.** 이유:
  1. 최종본은 v2 → v19까지 판을 쌓은 결과이고, 한 번에 도는 실행 스크립트가 없다. 판마다 `python -m src.vNN.run` 식의 명령을 순서대로 돌려야 한다.
  2. 스택의 절반을 차지하는 v10은 v2·v4·v5·v9·v11 단계의 저장된 예측 파일에 의존한다. 그 일부(TabM, STG, CatBoost)는 외부 GPU에서 학습했다. GPU 학습은 시드를 고정해도 장비가 다르면 값이 조금 달라질 수 있다.
  3. 팀 공유 자료를 `~/Downloads` 아래 경로에서 읽는 부분이 있다(`src/v8/core.py`의 SHARE 등). 코랩에서는 경로를 바꿔야 한다.
  4. 이 컴퓨터의 환경: Python 3.12.14, numpy 2.3.5, pandas 2.2.3, lightgbm 4.7.0, xgboost 3.4.1, catboost 1.2.10, scipy 1.18.1, scikit-learn 1.9.1. 코랩 기본 버전과 다르면 설치 명령으로 맞춰야 한다.
- **시상 전에 필요한 정리(아직 안 함)**: ① 전 단계를 순서대로 돌리는 노트북 1개와 단계별 산출물 해시 표, ② 자료 경로를 한 폴더로 모으기, ③ `requirements.txt`, ④ GPU 단계의 시드·장비 기록과, 재학습 시 허용 오차 설명. 저장된 중간 예측을 "입력 자료"로 인정받을 수 있는지 운영진에 확인하는 것이 가장 빠르다.
