# SINCON 베이스라인 파이프라인 분석

분석일: 2026-11-11. 기존 `outputs/baseline`의 모델·가중치·제출 파일을 수정하지 않고 OOF 오차 분해와 별도 진단 실험을 수행했다. 분석 대상은 Codex가 만든 초기 파이프라인이며, 대회 운영진의 공식 베이스라인과 구별한다.

## 1. 먼저 기준모델의 출처를 구분한다

| 구분 | 방법 | 학습 기준일·검증 기간 | 로컬 RMSLE |
|---|---|---|---:|
| 운영진 공식 베이스라인 | 지정 기간의 역·요일·시간별 log1p 평균 | 02-28 기준, 03-01~06-30 122일 | **0.3077006623** |
| 자체 계절 기준모델, 기존 점수 | 마지막 동일 요일 값 복사 | 02-27 기준, 02-28~06-30 123일 | **0.2910048489** |
| 자체 계절 기준모델, 공식 기간 비교 | 마지막 동일 요일 값 복사 | 02-28 기준, 03-01~06-30 122일 | **0.2897381688** |
| 자체 파이프라인 기존 앙상블 | 개발 OOF 가중 평균 + 로그 편향 보정 | 02-27 기준, 02-28~06-30 123일 | **0.2938525365** |

공식 코드는 [운영진 공지](https://www.kaggle.com/competitions/sincon-2026/discussion/757952)에서 확보했고 원본 그대로 실행해 공지의 0.30770을 재현했다. [공식 코드 재현 보고서](../official_baseline/README.md)를 참고한다. 공지의 Public 0.28264는 운영진이 기재한 값이며 이번에 제출해 측정한 값이 아니다.

`0.291005`는 다운로드한 공식 코드에서 나온 값이 아니다. 기존 파이프라인을 import하지 않고 원본 CSV만으로 다시 계산한 [독립 재현 코드](provenance/recompute_seasonal.py)와 [결과 JSON](provenance/seasonal_score_proof.json)에서도 0.29100484892830686이 나왔고 저장 OOF의 예측값과 전부 일치했다.

## 2. 가장 직접적인 악화 원인은 로그 편향 보정이다

같은 가중치와 같은 OOF 예측을 고정하고 보정 하나만 제거했다.

| 02-28~06-30 감사 구간 | RMSLE |
|---|---:|
| 기존 앙상블, bias=-0.0561728567 | 0.2938525365 |
| 같은 가중치, bias=0 | **0.2628118951** |
| 단순 계절 복사 | 0.2910048489 |
| 개발 전체에서 고른 단일 CatBoost | 0.2790557727 |
| 참고: 해당 구간 LightGBM large | 0.2539725321 |

가중 평균 자체는 이 구간에서 계절 복사보다 좋았다. 이후의 로그 보정이 예측을 너무 낮추면서 결과가 역전됐다. 원 코드의 `src/ensemble.py`는 개발 OOF 전체에서 `mean(log1p(y)-blend)`를 계산해 모든 미래 날짜에 같은 값을 더한다.

- 보정 전 감사 평균 로그오차는 이미 **−0.12571758**로 과소예측이었다.
- −0.05617286을 추가하면 **−0.18189044**로 더 낮아진다.
- 감사 log-MSE는 보정으로 **0.017279221 증가**, 같은 가중치 무보정 대비 **25.02% 증가**했다.
- 클리핑된 행이 없어 이 변화는 `MSE=오차 분산+평균오차²`로 정확히 분해된다. 분산은 그대로이고 평균오차 제곱만 커진다.
- 개발 fold1의 보정 전 평균 로그오차는 **+0.11776968**, fold2는 **−0.00540281**이었다. 이미 부호와 크기가 바뀌는데 합쳐서 만든 전역 보정값을 적용했다. 보정은 fold2에서도 0.228185→0.236286으로 악화시켰다.

따라서 우선 비교할 수정은 로그 보정 제거 또는 과거 fold에서 다음 fold로 이동시켰을 때 일관되게 좋아지는 경우에만 보정하는 규칙이다. **0.262812는 사후 원인분석 결과이며 새 독립 검증 점수가 아니다.** 현재 제출 파일에는 반영하지 않았다. 근거: [앙상블 분석](ensemble/ENSEMBLE_DIAGNOSIS_DRAFT.md), [정량 JSON](ensemble/summary.json).

## 3. 초기 신규 역 구간이 최종 모델 선택 목적과 다르다

첫 검증 구간에서 3107·3108·3109는 학습 이력이 없는 신규 역이다. 이들은 **6,588행, 4.1924%**에 불과하지만 LightGBM large의 로그 제곱오차 합 중 **78.850%**, XGBoost의 **82.309%**를 차지한다. 원단위 승차량이 작거나 극단적으로 잘못 예측된 신규 역은 RMSLE에도 큰 영향을 준다.

| 개발 fold1·2 합산의 평가 모집단 | CatBoost RMSLE | LightGBM large RMSLE |
|---|---:|---:|
| 모든 역 | **0.352903** | 0.491465 |
| 해당 origin에서 이력이 있는 역만 | 0.270628 | **0.269095** |

첫 fold의 신규 역은 최종 테스트 조건과 다르다. 실제 7~10월 테스트에는 학습 이력이 전혀 없는 station_id가 없다. 초기 구현은 신규 역 스트레스 검증과 기존 역의 미래 예측을 동일한 가중치 선택 기준으로 합쳐 사용했다. 이는 직접적인 미래 정보 누수는 아니지만, **모델 선택을 위한 검증 모집단이 실제 예측 모집단과 다르다는 설계 문제**다.

신규 역에서 XGBoost와 LightGBM의 극단적 반대 방향 오차가 서로 상쇄되는 가중치가 선택될 수 있다. 전체 개발의 최상 모델과 실제 배포 환경의 최상 모델이 같다고 볼 수 없다. cold-start는 별도 진단표로 보고하고 기존 역 미래 예측을 주 평가로 두는 후속 프로토콜이 적합하다. 단, 이 사후 발견으로 기존 audit를 다시 최적화한 뒤 새 홀드아웃처럼 보고해서는 안 된다. 근거: [CV 분석](cv/CV_AUDIT_NOTES.md).

## 4. 신경망은 절대 시간·이력 길이를 외삽하며 크게 흔들린다

완전한 123일 정답 창을 요구하므로 마지막 학습 특징 origin은 항상 cutoff보다 최소 123일 전이다. 최종 `history_days`는 기존 68역에서 학습 최대423→테스트546, 나머지 3역에서245→368로 모두 123일 초과한다. `date_index`도 학습28~545→테스트546~668이다. 신경망의 표준화는 범위 밖 입력을 제한하지 않는다.

원본 MLP를 같은 seed로 재학습해 저장 OOF를 재현한 뒤 `date_index`, `history_days` 두 특징만 제거하는 진단을 했다. 타겟·손실·epoch·다른 특징은 그대로다.

| 구간 | 원본 MLP | 절대 시간·이력 길이 제거 |
|---|---:|---:|
| 개발1 | 0.625472 | 0.442551 |
| 개발2 | 0.526600 | 0.245101 |
| 기존 감사 구간 | 0.331299 | 0.247719 |

훈련 점수는 거의 같았다. 예를 들어 개발2 훈련 RMSLE는 0.276677→0.275723인데 검증은 크게 달라졌다. 특징을 통한 외삽 문제가 일반화 실패의 상당 부분을 설명한다. 표준화 값을 ±5로 일괄 제한하는 방법은 fold2·3에서 악화돼, 무조건적인 클리핑도 답이 아니었다.

이 결과는 4개 고정 변형의 **사후 진단**이다. 0.247719를 새 모델의 공인 성능으로 주장하거나 기존 제출에 곧바로 섞지 않았다. 재현 코드: [analyze_neural.py](features/analyze_neural.py), 결과: [neural_ablations.csv](features/neural_ablations.csv), [특징 이동](features/neural_feature_drift.csv).

## 5. 연간 시차와 학습 표본의 구성도 달라진다

- `year364` 가용률은 sampled train→query가 개발2 **0→45.94%**, 감사 **7.71→95.91%**, 최종 **34.23→100%**다. 개발2에서는 학습에 아예 관측값이 없어서 연간 특징의 유용성을 평가할 수 없다.
- 마지막 학습 origin을 `cutoff-123`으로 제한하면 최근 정답은 학습에 들어오더라도 최근 상태의 특징과 짧은 horizon을 함께 학습할 기회가 없다. 최근 origin의 관측 가능한 부분 horizon을 허용하는 설계와 비교할 필요가 있다. 각 행의 정답 날짜가 cutoff를 넘지 않는다는 조건은 반드시 유지한다.
- 최종 학습 220,000행 중 고유 정답 키는 191,424개다. 같은 날짜를 여러 origin에서 예측하는 것은 정상 설계이지만 재사용 빈도가 학습 가중치를 바꾼다.
- 2026-03의 원본 관측당 선택 횟수는 평균0.4589회, 06월은0.1643회로 약2.79배 차이다. 최근28일은 학습 표본의2.6714%다. 고정 최대 행 수를 origin별로 균등 배분한 결과 최근 상태가 상대적으로 적게 학습된다.

이들은 전부 오류라고 단정할 수 있는 항목은 아니다. 다만 본 모델의 분포 변화와 표본 가중치 효과를 명시적으로 검증해야 한다. 세부 수치는 [cv_audit.json](cv/cv_audit.json)에 있다.

## 6. 어떤 날짜·역에서 악화됐는가

RMSLE는 구간별로 더할 수 없으므로 **로그 제곱오차 합(LSE)**을 분해했다. 기존 앙상블과 계절 복사의 전체 차이는 **+261.81 LSE**다.

- 공휴일 7일: **−1,653.75** 개선. RMSLE 0.60029→0.41891.
- 일반 날짜: **+1,915.56** 악화. RMSLE 0.260862→0.284553.
- 인천대공원역(3226): **+275.96** 악화. 4월 실제 평균293.9명에 계절 모델139.7명, 앙상블114.3명으로 봄 수요 증가를 과소예측했다. 원인을 특정 행사라고 확인한 것은 아니다.
- 월별 차이: 4월+689.98, 6월+219.59 악화, 3월−293.22와5월−365.77 개선.
- 문학경기장역 야간 급등은 큰 절대오차 원인이지만 **앙상블이 계절 모델보다 나빠진 원인 자체는 아니다**. 해당 역의 LSE는 오히려−136.77 개선됐다.

두 모델 점수차 0.002848에 대한 날짜 단위 paired-bootstrap 95% 구간은 **−0.025279~+0.026577**로 0을 포함한다. 작은 전체 순위차만으로 보편적인 우열을 확정할 수 없다. 반면 고정 가중치의 편향 보정 효과는 같은 예측에 대한 정확한 산술 분해다. 근거: [구간별 분석](segments/ANALYSIS_DRAFT.md), [상세 CSV](segments/segment_metrics.csv).

## 7. 상관계수 필터의 문제는 상대적으로 작다

LightGBM large는 small과 로그 잔차 상관이0.95를 넘어 제외됐다. 기존 small 가중치만 large로 교체하는 진단에서 감사 RMSLE는0.293853→0.292692다. 상관 필터를 비활성화하고 **개발 자료에서만** 다시 적합한 결과도 보정 포함0.292430, 보정 제거0.261691이었다.

중복 모델 제거가 추가적인 개선 가능성을 줄였지만 주된 악화 원인은 아니다. ‘상관이 높으면 항상 제외’보다 개발 검증에서 실제 추가 개선이 있는지를 보거나, 가중치 규제를 통해 중복을 다루는 방향이 적합하다. 이를 이미 본 감사 구간에 맞춰 결정하면 안 된다.

## 8. 후속 수정의 우선순위와 평가 조건

1. **비교 명칭과 공식 코드 고정:** 운영진 원본·자체 계절 복사·현재 앙상블을 구분하고 동일 origin·동일 검증 행에서 비교한다.
2. **로그 보정의 이동 검증:** 보정 없는 앙상블을 기본 후보로 두고 과거 fold에서 추정한 보정이 다음 fold에서도 개선되는지 평가한다. 원단위 MBE 보정으로 대체하지 않는다.
3. **cold/warm 분리:** 실제 테스트와 같은 기존 역 예측을 주 점수로, 신규 역은 별도 스트레스 지표로 보존한다.
4. **MLP 시간 특징 정비:** 절대 날짜·이력 길이 제외와 안정적인 상대/주기 특징을 고정된 후속 프로토콜에서 비교한다.
5. **학습 창·표본 가중치 비교:** 최근 origin의 부분 horizon 포함, 날짜별 중복 가중치, 더 큰 표본 크기를 독립적인 실험으로 분리한다.
6. **캘린더·계절·역 상호작용:** 비공휴일의 과소예측 및 봄철 특정 역 증가를 사전 정보만으로 모델링한다. 7월 이후 실제 수요·날씨·행사 결과는 사용하지 않는다.

후속 평가는 nested rolling 형태로 각 바깥 origin의 가중치·보정을 그 이전의 inner OOF만으로 정한다. 바깥 구간에서 최선의 변형을 계속 고르는 방식은 다시 선택 편향을 만든다. 이미 열람·분석한 기존 fold3을 ‘새로운 미사용 홀드아웃’이라고 부르지 않는다. 이 보고서는 **원인분석 완료**이며 후속 배포 모델의 개선 검증 완료를 뜻하지 않는다.
