## 7호선 부천·인천 구간 과거 승하차 (2015-01 ~ 2021-12) ✅ 새로 확보
- 출처: 서울 열린데이터광장 **OA-12252 지하철 호선별 역별 시간대별 승하차 인원** (`CardSubwayTime` API, 샘플키로 받음). 스크립트 `analysis/fetch_seoul_line7.py`
- 파일: `data/external/seoul_line7_monthly_hourly_2015_2021.csv` (월 × 역 × 시간, 18,144행, 빠진 달 없음)
- 역 9개: 까치울 3753 ~ 부평구청 3761. **산곡 3762·석남 3763 은 없음** (2021-05 개통, 처음부터 서울 데이터에 없음)
- 2022-01 부터는 운영 기관이 바뀌어 서울 데이터에서 빠짐 (부평구청 2021-12 198,789명 → 2022-01 14명)
- **일별이 아니라 월별 합계**(시간대별). 일별(OA-12914)은 샘플키가 안 돼서 서울시 인증키가 있어야 함
- 인천1·2호선은 서울 데이터에 없음 → 2025년 이전 자료는 인천교통공사 요청이 필요

### 대회 데이터와 맞는지
- 시간대 모양: 부평구청 2019-10 vs 2025-10 상관 **0.97**
- 수준(2025-09 / 2019-09): 대부분 0.9~1.2배. 단, **부평구청 0.58**(2021 석남 연장으로 종점이 아니게 됨), **부천종합운동장 0.59**(원인 확인 필요) → 수준보다 **계절 비율**로 쓰는 게 안전

## V리그 배구 인천 홈경기 (2015-16 ~ 2026-27 시즌) ✅
- 파일: `data/external/games_kovo_incheon.csv` (452경기: 날짜, 시작·종료 시각, 남/녀, 홈·원정, 경기장). 관중 수는 API에 없음
- 출처: KOVO 공식 사이트가 쓰는 공개 API `user-api.kovo.co.kr/games/schedules`. 스크립트 `analysis/fetch_kovo.py`
- 경기장: 대한항공은 계양체육관, 흥국생명은 계양(~2021) → **삼산월드체육관(2021-22 시즌~)**
- KOVO컵(8~10월)은 인천에서 열린 적이 없음

### 효과 (2025-01 ~ 2026-04 시즌 기간)
- **삼산체육관역 3759**: 평일 19시 경기 → **21시 승차 81 → 749명 (약 9배)**, 22시 67 → 246. 주말 16시 경기 → 17~18시 승차 2~4배
- **계양체육관**: 계양~작전역 어디에도 효과 없음 (걸어갈 만한 역이 없음) → 역 매핑 비움
- 테스트 기간(7~10월) 영향: **거의 없음**. 10/31 대한항공 개막전(계양, 효과 없음)뿐. 흥국생명 첫 홈경기는 11/1
- → 앞서 "원인 불명"이던 **삼산체육관역 평일 밤 급증의 원인은 흥국생명 홈경기**
