> **✅ 2026-11-13 저녁 받아서 확인했어요** → `데이터_공유_README.md` 6-3절 (19), 47~51번 파일.
> - **2019·2020년은 역 × 일 × 시간대**(1·2호선)였어요. 공사 게시판 월별과 칸마다 같아요.
> - 2022-01 ~ 2026-06은 역 × 일 (1·2·7호선). train과 하루 합 차이 중간값 0.26%.
> - 2021년은 노선 합계만 있어요(아래 표의 "7호선 일별 시간대별 2021"도 노선 합계였어요).
> - 판마다 집계 기준이 두 가지(F/L)라서 `basis` 열로 표시하고 둘 다로 바꾼 값을 넣었어요. **train도 2025년(L)과 2026년(F) 기준이 달라요.**
>
> 아래 표와 설명은 받기 전에 적은 추정이에요.

README 3절에는 "과거는 월 합계만 있어요"라고 적었는데, **공공데이터포털 인천교통공사 자료에 해마다 올린 옛 파일이 '주기성 과거 데이터'로 남아 있어요.** 로그인·인증키 없이 받을 수 있어요. 모두 2026-06 이전이라 규칙상 문제없어요.

**왜 1순위인가요**
- 지금은 과거 효과를 **월 합계**(1번 파일)와 서울시 자료(41번, 7호선 9개 역·환승 상대역)로만 봐요. 이 파일들이면 **71개 역 전부의 일별 승차를 2019 ~ 2024년까지** 볼 수 있어요(코로나 구간을 빼도 2019년, 2022 하반기 ~ 2024년).
- 그러면 SSG 경기·콘서트·축제·추석의 **날짜별 효과를 역마다 6년 치**로 다시 잴 수 있어요. 특히 **9/26처럼 train에 없는 "추석 다음 토요일"** 같은 날을 과거 연도에서 찾을 수 있어요.
- 7호선 2021년판과 1·2호선 2019·2020년판은 이름에 "시간대별"이 있어서, 받아 보면 **과거 일 × 시간대** 자료일 수도 있어요.
- 15004329의 2016·2017년 2호선 파일로 README 12절의 남은 일 "**2호선 2016-08 ~ 2017-02 빈 구간**"을 채울 수 있을 것 같아요.

**받기 전에 알아 둘 것 (추정)**
- 현재판 설명이 "2025-07-01 ~ 2026-06-30"이라서, 과거판도 대부분 **7월 ~ 이듬해 6월** 1년 치로 보여요. 20191231·20201231·20211231은 1 ~ 12월, 20230531은 끝이 5월이에요. **2022년 1 ~ 6월은 15004329의 20220630판으로 메워질 것 같아요.** 정확한 기간·열 이름은 받아서 확인해야 해요.
- 현재판은 1호선 검단 연장 3개 역(2025-06-28 개통)을 빼고 있어요.
- 받는 곳: 각 데이터셋 페이지 맨 아래 **"주기성 과거 데이터"** 표 → 파일 이름 클릭 → CSV. 과거판 식별값은 `analysis/portal_scan_20261113/past_versions_subway.csv`에 정리했어요.
